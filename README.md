# الجمعة البيضاء: صور ومراجع

الملفات دي مش جزء من الباندل، ومنفصلة عن `main` عشان حجم الباندل المضغوط يفضل أقل من 1 MB.

- `research/`: الـ screenshots اللي الأفكار اتبنت عليها (`docs/ideas.md` في `main`)
- `logo/`: لوجو القوالب للوضع الفاتح والداكن، والقوالب بتستخدمه من هنا
- `marketplace/`: أيقونة الباندل وصور متجر الثيمات
- `templates-thumbs/`: الصور المصغرة للقوالب
